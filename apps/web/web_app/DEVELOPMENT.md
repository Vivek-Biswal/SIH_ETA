# Website development

Use the documentation for the installed Next.js version before changing routing,
rendering or configuration. This project uses Next.js 16 and React 19; older
examples may rely on different APIs or conventions.

The versioned guides are available under `node_modules/next/dist/docs/`, resolved
from this directory. Follow deprecation notices and run the checks documented in
[README.md](README.md) before publishing a change.
